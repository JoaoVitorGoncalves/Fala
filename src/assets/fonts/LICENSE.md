# Licenças das fontes empacotadas

Ambas as fontes são distribuídas sob a SIL Open Font License 1.1 (OFL-1.1) e
podem ser empacotadas em aplicativos livremente, inclusive comerciais.

## Geist Sans

- Fonte: https://vercel.com/font (Vercel), distribuída via Fontsource.
- Arquivos: `geist-sans-latin-{400,500,600}-normal.woff2`
- Licença: SIL OFL 1.1 — https://github.com/vercel/geist-font/blob/main/LICENSE.TXT

## JetBrains Mono

- Fonte: https://www.jetbrains.com/lp/mono/ (JetBrains), distribuída via Fontsource.
- Arquivos: `jetbrains-mono-latin-{400,500,600}-normal.woff2`
- Licença: SIL OFL 1.1 — https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt

Os subsets "latin" cobrem português do Brasil (incluindo acentos e cedilha).
Fonte dos arquivos: https://fontsource.org/ (CDN jsDelivr, pacote `fontsource/fonts`).
